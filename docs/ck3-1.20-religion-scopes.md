# Religion callbacks and ROOT in CK3 1.20

Checked against CK3 1.20.0.4 with a throwaway mod. The two warnings below reflect native scope errors. The validator should continue reporting them.

`on_faith_created` has a faith as its root. Entering a character scope does not change that root. Native tests confirmed that both `order_by` and `create_character.gender_female_chance` preserve it when evaluating the script values used here.

## Head-of-faith selection

The call in `common/on_action/religion_on_actions.txt` enters `ordered_faith_character` and evaluates `head_of_faith_selection_weight`. The candidate is a character, while ROOT remains the faith.

In `common/script_values/02_religion_values.txt`, the value enters `any_sub_realm_barony` and tests `is_holy_site_of = root.faith`. CK3 rejects the `faith` link on a faith root. With the same candidate, a character-root control succeeds, as does a faith-root control using an explicit reference to the candidate's faith.

Within this particular barony iterator, `prev.faith` refers to the candidate's faith. That replacement was also executed natively with a selected candidate and produced no scope errors. The candidate must actually be selected: an empty iterator is not evidence that the value works.

## Creating a spiritual head

`set_up_dynamic_spiritual_hof_title_effect` can reuse an existing cleric, a clerical puppet, a realm priest or a theocratic vassal. Its fallback creates a character and uses `root_faith_clergy_gender_female_chance`.

That value, defined in `common/script_values/01_dynamic_values.txt`, reads `root.rite`. CK3 rejects that link when ROOT is a faith, even with a character as the current scope. Both doctrine checks fail, leaving the value's 50-percent fallback instead of the intended clergy restriction. A control using the creator's rite succeeds.

The helper already saves its creator as `scope:hof_creator`. Its gender calculation can use that character's rite, consistently with the faith and rite assigned to the new character. The existing-cleric branch can succeed while the fallback still contains an invalid root dependency; a successful call through that branch does not test character creation.

A native fixture with a lay castle holder, a capital, no chaplain, no clerical puppets and no matching theocratic vassals forced the creation branch. The original helper created a new head and logged the invalid `root.rite` accesses. A copy using the explicit creator in an inline gender value also created a new head and produced no errors attributed to that helper. A separate inline-value control produced a male character for the tested male-only clergy rite.

## Regression coverage

`test_mod26_religion_values_keep_the_callers_root` covers both invalid faith-root calls, valid character-root calls and controls with candidate/creator-relative references. It protects the warnings without requiring an installed copy of CK3. Native tests additionally used misspelled `fatih` and `rtie` links as negative controls, retained raw logs and checked that the player's profile was restored.

## General validator behavior

The built-in callback contract applies to every mod, including custom on-actions
chained from `on_faith_created`. It supplies a faith root, `founder: character`,
`old_faith: faith`, `old_rite: rite` and `diverged: bool`. Conversion callbacks
retain their character root. No project names or mod-specific exceptions are
part of these rules.

Trait validation also checks the engine's `trait_<group>` localization key for
both `group` and `group_equivalence`, using the languages selected for validation.
A custom trait `name` does not replace its group label. Group descriptions are
not required. `test_mod27_chained_faith_callbacks_and_translated_trait_groups`
covers chained callbacks and groups with complete, partial and missing translations.

Validation on real mods uses their original scripts without compatibility addons.
The native tests above establish that the two original root mismatches should
remain diagnostics when those scripts are encountered in any mod.
